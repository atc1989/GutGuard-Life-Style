# First session after register

Register used to copy the new name onto the Maria Santos demo (₱1,750, four invites, 10 days left, BASE 2/5). That was a lie.

## Day zero

1. `/register` writes an empty member session: 0 points, no invites, no bottle.
2. `/card` is the product — their name, tap to flip, show at the door. After claim, **How points work**, not “see how you earned these.”
3. `/nearly` is a legend: ₱0, empty invites, **Back to my card**. It does not start the protocol.
4. `/app/health` stays empty until a bottle exists. A mock order grants 30 days per bottle and opens the calendar.

Sign-in resumes by phase: members land on `/app/health`; everyone else on the door.

## Sign out

**Sign out** lives on the door, Nearly Free, and Settings. It clears the mock `localStorage` session and the Supabase cookie, then returns to `/`.
